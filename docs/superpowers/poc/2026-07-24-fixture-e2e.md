## Browser E2E Not Claimed

The following checks require the unpacked extension in the user's normal Chrome
profile and remain pending:

- options page saves LinkMaster base URL and token;
- Test Connection reports the local API result;
- side panel loads the active Campaign;
- one visible automation tab is reused across Items;
- content-script inspection and fill messages cross the real extension
  boundary;
- the side panel pauses at `awaiting_review`;
- only a user click can submit;
- a saved terminal result appears in LinkMaster before the next Item opens;
- pause, skip, retry save, cancel, and complete controls work visually;
- compact and narrow side-panel layouts do not overlap.

These are product acceptance checks, not blockers for completing the code and
packaging work. They must pass before using the extension on external pages.
